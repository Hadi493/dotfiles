# Host: cyber-green

| Field | Value |
|---|---|
| OS | Arch-based (`cg-os`), hostname `cyber-green` |
| Compositor | Hyprland 0.57, no display manager, TTY login |
| Panel | `eDP-1`, 1920x1080, scale 1 (default in `hyprland.lua`) |
| GPU | Intel UHD 630 — animations, blur and shadows are disabled for it |
| External | DDC/CI monitor via `ddcutil-service` (`scripts/monitor`) |
| Backlight | none — `F3`/`brightnessctl` targets the LAN LED (see caveats) |

## Machine-specific state (never tracked)

- `~/.config/hypr/monitors.local.lua` — monitor/output override; replaces the
  default `hl.monitor()` in `hyprland.lua`.
- `~/.config/fish/fish_variables`, `~/.config/fish/user.fish` edits — fish
  universal variables and shell overrides.
- `~/.local/share/wayland-sessions/hadi-hyprland.desktop` — generated by
  `./deploy hypr` with this machine's absolute paths.

Everything else in this directory is documentation. Do not put secrets here.
