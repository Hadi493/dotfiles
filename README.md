# [Hadi Alam](https://github.com/Hadi493)'s Personal dotfiles

A simple config files for i3 and hyprland.

## Quick start

Clone the repo
```bash
git clone https://github.com/Hadi493/dotfiles.git
```
for hyprland
```bash
git switch hypr
```
for i3wm
```bash
git switch i3
```

And read the readme for usage.
